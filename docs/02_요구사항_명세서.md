# 요구사항 명세서

### 기능 요구사항 명세서

| No | ID | 화면명 | 기능명 | 기능상세 | 우선순위 |
|---|---|---|---|---|---|
| 1 | FR-01 | 메인화면 | 공공시설 목록 조회 | 용인시 공공시설 목록을 조회하고 시설명, 유형, 위치 등의 기본정보를 제공 | 필수 |
| 2 | FR-02 | 메인화면 | 시설 검색 | 시설명 및 시설 유형을 기준으로 원하는 공공시설을 검색 | 필수 |
| 3 | FR-03 | 메인화면 | 시설 유형 필터링 | 도서관, 체육시설, 문화시설, 복지시설 등 시설 유형별로 목록을 필터링 | 필수 |
| 4 | FR-04 | 시설 상세 화면 | 시설 상세정보 조회 | 선택한 시설의 시설명, 주소, 운영시간, 휴관일 등의 상세정보를 제공 | 필수 |
| 5 | FR-05 | 지도 화면 | 공공시설 위치 표시 | 지도 API를 활용하여 용인시 공공시설의 위치를 마커 형태로 표시 | 필수 |
| 6 | FR-06 | 지도 화면 | 시설 위치 상세정보 | 지도에 표시된 마커를 선택하면 해당 시설의 이름, 주소, 운영시간 등을 확인 가능 | 필수 |
| 7 | FR-07 | 시간대별 검색 화면 | 요일 선택 | 사용자가 원하는 요일을 선택하여 시설 운영 여부를 검색 가능 | 필수 |
| 8 | FR-08 | 시간대별 검색 화면 | 시간 선택 | 사용자가 원하는 이용 시간을 설정 가능 | 필수 |
| 9 | FR-09 | 시간대별 검색 화면 | 이용 가능 시설 검색 | 선택한 요일과 시간에 실제 운영 중인 공공시설 목록을 제공 | 필수 |
| 10 | FR-10 | 시간대별 검색 화면 | 운영 상태 표시 | 시설별 운영 여부를 운영 중, 운영 종료, 휴관 등으로 구분하여 표시 | 필수 |
| 11 | FR-11 | AI 분석 화면 | 시설 운영 현황 분석 | 시설별 운영시간과 지역별 시설 분포 데이터를 분석 | 필수 |
| 12 | FR-12 | AI 분석 화면 | 개선 필요 시설 탐색 | 운영시간이 제한적이거나 특정 시간대 이용이 어려운 시설을 식별 | 필수 |
| 13 | FR-13 | AI 분석 화면 | AI 개선안 추천 | 분석 데이터를 바탕으로 시설 운영시간 조정 및 접근성 개선 방안을 제안 | 필수 |
| 14 | FR-14 | AI 분석 화면 | 개선안 추천 근거 제공 | AI가 제안한 개선 방안에 대한 데이터 및 분석 근거를 함께 제공 | 필수 |
| 15 | FR-15 | 접근성 분석 화면 | 지역별 시설 접근성 분석 | 용인시 행정구역별 공공시설 분포와 이용 가능 현황을 분석 | 후순위 |
| 16 | FR-16 | 접근성 분석 화면 | 시간대별 접근성 분석 | 시간대별 이용 가능 시설 수를 비교하여 접근성 차이를 분석 | 후순위 |
| 17 | FR-17 | 접근성 분석 화면 | 접근성 취약지역 탐색 | 시설 분포 및 운영시간을 바탕으로 접근성이 상대적으로 낮은 지역을 도출 | 후순위 |
| 18 | FR-18 | 교통 분석 화면 | 주변 버스정류장 조회 | 공공시설 주변의 버스정류장 위치 정보를 제공 | 추가 |
| 19 | FR-19 | 교통 분석 화면 | 버스 노선 정보 조회 | 시설 주변을 운행하는 버스 노선 정보를 제공 | 추가 |
| 20 | FR-20 | 교통 분석 화면 | 대중교통 접근성 분석 | 버스정류장 및 노선 정보를 활용하여 시설별 대중교통 접근성을 분석 | 추가 |
| 21 | FR-21 | 개선 효과 분석 화면 | 개선 전후 현황 비교 | 시설 운영시간 변경 전후의 시간대별 이용 가능 시설 수를 비교 | 추가 |
| 22 | FR-22 | 개선 효과 분석 화면 | 개선 효과 시각화 | 운영시간 조정에 따른 예상 접근성 변화를 그래프 및 표로 시각화 | 추가 |

### 비기능 요구사항 명세서

| No | ID | 화면명 | 기능명 | 기능상세 | 우선순위 |
|---|---|---|---|---|---|
| 1 | NFR-01 | 전체 화면 | 사용자 편의성 | 사용자가 복잡한 절차 없이 직관적으로 서비스를 이용할 수 있도록 UI를 구성 | 필수 |
| 2 | NFR-02 | 전체 화면 | 응답 속도 | 시설 검색 및 정보 조회 결과를 목표 응답시간 5초 이내에 제공하도록 설계 | 필수 |
| 3 | NFR-03 | 전체 화면 | 데이터 정확성 | 시설 위치, 운영시간 등 제공 정보가 원본 공공데이터와 일치하도록 관리 | 필수 |
| 4 | NFR-04 | 전체 화면 | 데이터 최신성 | 공공데이터의 갱신 주기를 확인하고 최종 데이터 수집일을 관리 | 필수 |
| 5 | NFR-05 | 전체 화면 | 시스템 안정성 | 외부 API 오류 및 데이터 수집 실패 상황에서도 서비스 전체가 중단되지 않도록 예외 처리를 수행 | 필수 |
| 6 | NFR-06 | 데이터 관리 | 데이터 품질 관리 | 운영시간 누락, 주소 오류, 중복 시설 등 데이터 오류를 식별하고 처리 | 필수 |

### MVP 기능

| 기능 | 상세 내용 | 우선순위 |
|---|---|---|
| 공공시설 조회·검색 | 용인시 공공시설의 위치, 유형, 운영시간 등 조회 | 필수 |
| 지도 기반 시설 시각화 | 지도에 공공시설 위치 및 관련 정보 표시 | 필수 |
| 시간대별 이용 가능 시설 검색 | 특정 요일·시간에 이용 가능한 시설 조회 | 필수 |
| AI 기반 개선안 추천 | 시설 운영시간 조정 및 접근성 개선 방안 제안 | 필수 |
| AI 기반 접근성 분석 | 지역별·시간대별 시설 접근성 분석 및 취약지역 탐색 | 필수(5순위로 두고 시간 부족하면 추가기능으로 일단 제외) |
| 교통 접근성 분석 | 주변 버스정류장, 버스 노선 및 도착정보 등을 활용한 접근성 분석 | 논의 |
| 개선 효과 시각화 | 현재 현황과 개선 시나리오의 예상 효과 비교 | 추가 후보 |
